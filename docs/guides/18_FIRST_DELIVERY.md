# 18 · 처음 사용하는 사람에게 전달하기

SDK 0.3.17와 모델 데이터는 별개입니다. 받는 사람이 **모델만 보는 사용자**, **외부 앱을 만드는 개발자**, **편집기로 제작하는 사용자** 중 누구인지에 따라 준비물을 정합니다.

## 전달할 묶음

| 받는 사람 | 전달할 것 | 첫 실행 |
|---|---|---|
| 모델 조회 사용자 | 공식 SDK Git 주소(권장) 또는 전체 ZIP, 모델 이름, SDK 연결 주소 또는 청크 폴더 전체, 아래 실행 안내, 담당자 연락처 | Git clone 또는 ZIP 전체 해제 → examples/test-server.cmd → Chrome/Edge |
| 외부 앱 개발자 | 공식 Git 주소와 고정 태그 v0.3.17, API/17 가이드, 모델 연결 정보, 화면/업무 데이터 요구사항 | 패키지 설치 또는 정적 모듈 포함 → 앱에 canvas 배치 |
| 편집기 제작 사용자 | 별도 Windows x64 편집기 배포 ZIP, 레벨 백업 ZIP이 있으면 함께, 저장·복구·게시 절차, 지원 Unreal 버전 | 편집기 ZIP 전체 해제 → DTWebEditor.exe |

공식 SDK: `https://github.com/jonemos/DTDelivery-SDK` · 배포 기준 태그: `v0.3.17`. 편집기 실행 파일은 SDK Git에 포함되지 않습니다. 편집기 ZIP의 exe·resources·DLL 등을 함께 유지하며 exe만 떼어 전달하지 않습니다. Windows 배포 ZIP은 설치 프로그램이 아닌 압축 해제 실행본입니다.

원격 연결 주소는 제작자의 **SDK 연결 주소**를 그대로 전달합니다. 브라우저에 들어가는 것은 읽기용 주소이며 쓰기용 계정·키는 전달하지 않습니다. 로컬은 `delivery-head.json`·`objects`·`releases` 또는 `levels`를 포함한 내보내기/게시 저장소의 전체 폴더를 전달합니다. `.uasset`, `.uproject`, 편집기 내부 데이터베이스만 전달해서는 SDK가 모델을 열 수 없습니다.

## 제작자가 먼저 할 일

1. 편집기에서 필요한 레벨을 저장하고 텍스처·가져오기 경고를 확인합니다. 실패 항목이 있으면 해당 항목을 복구하고 저장합니다.
2. 통합레벨에 저장한 레벨을 추가하고 위치·회전·배율과 필요한 객체를 확인한 뒤 통합레벨을 저장합니다.
3. **청크 패키지**에서 원격 게시 또는 전체 패키지 폴더 내보내기를 완료합니다. SDK에는 완료된 결과를 전달합니다.
4. 같은 SDK 버전으로 모델 목록·열기·텍스처 준비·선택·재열기를 확인합니다. 화면 비교에는 같은 카메라·언릿/라이팅·환경광·품질·텍스처 설정을 사용합니다.
5. 원격은 수신자 웹 origin의 공개 읽기/CORS를 확인하고, 로컬은 폴더 구조를 유지합니다. 다른 PC 검증을 하지 않았다면 확인 범위를 명시합니다.

## 조회 사용자에게 그대로 전달할 실행 안내

1. Git이 설치된 PC는 아래 명령으로 쓰기 가능한 폴더에 처음 한 번 SDK를 받습니다. Git이 없는 PC는 SDK ZIP을 **전체 압축 해제**합니다. 압축 파일 내부에서 실행하지 않습니다.
2. `examples/test-server.cmd`를 실행하고 실행 창을 유지합니다. Windows의 기본 PowerShell을 사용하며 Node.js·pnpm·Python 설치는 필요 없습니다.
3. Chrome/Edge의 테스트 페이지를 엽니다. 기본 저장소에 모델이 있으면 이름을 선택하고 **게시본 열기**를 누릅니다. 다른 저장소는 **청크 위치**에 전달받은 주소를 넣고 **목록 조회**를 누릅니다.
4. 로컬 파일을 받은 경우 **청크 폴더 선택**에서 전달받은 루트를 고르고 읽기 권한을 허용합니다. 브라우저에서 ZIP 파일 자체를 선택하지 않습니다.
5. 로드와 텍스처 적용 완료를 기다립니다. 색상은 언릿으로 확인할 수 있고, 라이팅은 조명·환경광 설정에 따라 달라집니다.
6. 우클릭+WASD/QE로 이동, Alt+좌클릭으로 회전, 가운데 드래그로 평행 이동, 휠로 확대합니다. 액터 목록에서 검색·선택하고 **선택에 초점**을 사용할 수 있습니다.
7. 끝나면 페이지를 닫고 서버 창에서 Ctrl+C를 누릅니다. SDK 갱신은 서버 종료 → 루트 update.cmd → test-server.cmd 재실행 순서입니다. 모델 업데이트는 제작자의 재게시로 별도로 진행됩니다.

처음 받을 때만 실행합니다. 이후에는 받은 폴더의 `update.cmd`를 사용하며 다시 clone할 필요가 없습니다.

```powershell
git clone https://github.com/jonemos/DTDelivery-SDK.git
cd DTDelivery-SDK
.\examples\test-server.cmd
```

## 편집기 제작 사용자에게 추가할 안내

편집기에서 새 레벨 저장·레벨 열기·백업 내보내기/복구부터 확인합니다. 실행 파일이 있는 폴더와 작업 저장소를 구분하고, 배포 ZIP을 교체하기 전에 작업 레벨을 백업합니다. 개발판과 배포판의 저장 채널이 다르므로 개발판의 작업이 자동으로 나타난다고 안내하지 않습니다. 옮길 레벨은 앱의 검증된 백업 ZIP으로 복구합니다.

새 외부 레벨·에셋은 편집기의 **언리얼 연동**으로 가져옵니다. 선택한 Unreal 프로젝트의 Plugins/DTWebImportTools에 연결 도구를 설치하며 최초 설치/업데이트에는 정상 Unreal 재시작이 필요할 수 있습니다. 원본 콘텐츠를 자동 덮어쓰는 기능은 아닙니다. 포함된 native 베이크 도구는 검증된 UE 5.5.4 대상이므로 다른 엔진 버전 지원을 가정하지 않습니다. 해당 Unreal 프로젝트·버전에 맞는 연결 상태를 확인하세요.

목록이 비면 게시 완료·구역·주소를 확인하고, 흰색/회색이면 텍스처 준비와 베이스 컬러 선택을 확인합니다. 어두우면 언릿 또는 환경광으로 비교합니다. 해시·참조 오류는 제작자가 원본 게시 결과를 복구해야 합니다. SDK 파일을 직접 수정하거나 검사를 끄지 않습니다. 개발자는 [17 · 호스트 적용](17_HOST_INTEGRATION.md), 업데이트 담당자는 [업데이트·복구](../UPDATING.md)를 함께 받습니다.
